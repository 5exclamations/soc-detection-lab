## SOC-API-001 - API Enumeration - High Rate of Authorization or Not-Found Errors

A client generated 30 or more 401/403/404 API responses within one minute (object ID walking, endpoint probing).

- **Severity:** medium
- **Logic:** event_count over ['soc_api_error'] grouped by ['src_ip'] within 1m, condition {'gte': 30}
- **ATT&CK:** T1595 Active Scanning; tactics: reconnaissance
- **Known false positives:** Client bug looping on an expired token; Load tests against non-production data in production
- **Tuning:** Differentiate 401 storms (broken client) from 403/404 mixes (probing)
- **Limitations:** Rate-based; slow enumeration stays under the threshold. ATT&CK mapping is approximate (no dedicated API-enumeration technique).
- **Runbook:** [docs/runbooks/api.md#soc-api-001](../docs/runbooks/api.md#soc-api-001)
- **Source file:** `rules/api.yml`

## SOC-API-002 - Large API Data Export

An export endpoint returned 50 MB or more to a caller other than the allowlisted BI service.

- **Severity:** high (+1 if an `adm-`/root account is involved)
- **Logic:** single-event Sigma selection
- **ATT&CK:** T1213 Data from Information Repositories; tactics: collection
- **Known false positives:** New legitimate integrations before they are added to the allowlist
- **Tuning:** Replace static size threshold with per-principal baseline
- **Limitations:** Static 50 MB threshold; many small requests that sum to a large volume are not detected.
- **Runbook:** [docs/runbooks/api.md#soc-api-002](../docs/runbooks/api.md#soc-api-002)
- **Source file:** `rules/api.yml`

## SOC-API-003 - API Key Used From Multiple Source Addresses

A single API key was used from three or more source IPs within ten minutes (possible key theft or sharing).

- **Severity:** high
- **Logic:** value_count over ['soc_api_call'] grouped by ['api_key_id'] within 10m, condition {'gte': 3, 'field': 'src_ip'}
- **ATT&CK:** T1550.001 Use Alternate Authentication Material: Application Access Token; tactics: lateral-movement
- **Known false positives:** CI/CD runners or autoscaled workers sharing one key; Mobile clients roaming across networks
- **Tuning:** Issue per-runner keys or allowlist the runner CIDR for shared service keys
- **Limitations:** Cannot distinguish legitimate fan-out from theft without a per-key baseline of expected sources.
- **Runbook:** [docs/runbooks/api.md#soc-api-003](../docs/runbooks/api.md#soc-api-003)
- **Source file:** `rules/api.yml`

## SOC-AUTH-001 - Excessive Authentication Failures Against One Account

Ten or more failed logins for the same account from the same source IP within five minutes, consistent with online password guessing.

- **Severity:** medium (+1 if an `adm-`/root account is involved)
- **Logic:** event_count over ['soc_auth_failure'] grouped by ['src_ip', 'user'] within 5m, condition {'gte': 10}
- **ATT&CK:** T1110.001 Brute Force: Password Guessing; tactics: credential-access
- **Known false positives:** Misconfigured service accounts or scripts retrying a stale password; Users locked out behind a shared NAT address
- **Tuning:** Suppress known service accounts from internal subnets after owner confirmation; Raise threshold for NAT egress ranges
- **Limitations:** Per-(IP,user) counting misses low-and-slow guessing and attacks distributed across many IPs.
- **Runbook:** [docs/runbooks/authentication.md#soc-auth-001](../docs/runbooks/authentication.md#soc-auth-001)
- **Source file:** `rules/auth.yml`

## SOC-AUTH-002 - Password Spraying - Many Accounts From One Source

Failed logins against six or more distinct accounts from a single source IP within ten minutes.

- **Severity:** high (+1 if an `adm-`/root account is involved)
- **Logic:** value_count over ['soc_auth_failure'] grouped by ['src_ip'] within 10m, condition {'gte': 6, 'field': 'user'}
- **ATT&CK:** T1110.003 Brute Force: Password Spraying; tactics: credential-access
- **Known false positives:** Corporate NAT / VPN egress where several users mistype passwords at once; Vulnerability or identity-security scanners
- **Tuning:** Allowlist authorized scanner IPs; Tune the distinct-user threshold per egress range
- **Limitations:** Sprays that stay under six accounts per IP per 10 minutes, or rotate IPs, are not detected.
- **Runbook:** [docs/runbooks/authentication.md#soc-auth-002](../docs/runbooks/authentication.md#soc-auth-002)
- **Source file:** `rules/auth.yml`

## SOC-AUTH-003 - Successful Login Following a Failure Burst

A successful login from a source IP within fifteen minutes of that IP producing eight or more authentication failures. Strong indicator that guessing or spraying succeeded.

- **Severity:** high (+1 if an `adm-`/root account is involved)
- **Logic:** temporal_ordered over ['soc_auth_failed_burst', 'soc_auth_success'] grouped by ['src_ip'] within 15m
- **ATT&CK:** T1078 Valid Accounts, T1110 Brute Force; tactics: credential-access, initial-access
- **Known false positives:** A service account whose credential was fixed after a retry storm; Users behind shared NAT who eventually succeed
- **Tuning:** Correlate with account lockout policy; Exclude confirmed service-account remediation windows
- **Limitations:** Requires the success to come from the same IP as the failures; attackers rotating IPs before the successful attempt break the link.
- **Runbook:** [docs/runbooks/authentication.md#soc-auth-003](../docs/runbooks/authentication.md#soc-auth-003)
- **Source file:** `rules/auth.yml`

## SOC-AUTH-004 - Successful Logins From Multiple Countries Within One Hour

One account authenticated successfully from two or more countries within an hour (impossible travel proxy).

- **Severity:** medium (+1 if an `adm-`/root account is involved)
- **Logic:** value_count over ['soc_auth_success'] grouped by ['user'] within 1h, condition {'gte': 2, 'field': 'src_country'}
- **ATT&CK:** T1078 Valid Accounts; tactics: initial-access, persistence
- **Known false positives:** Corporate VPN / split-tunnel exits in different countries; Mobile carriers and CGNAT with inaccurate GeoIP
- **Tuning:** Exclude VPN egress ranges once enumerated; Use distance/time rather than country mismatch if lat/long is available
- **Limitations:** Country granularity only; no distance/time computation and no baseline of each user's normal locations.
- **Runbook:** [docs/runbooks/authentication.md#soc-auth-004](../docs/runbooks/authentication.md#soc-auth-004)
- **Source file:** `rules/auth.yml`

## SOC-WEB-001 - Web Content Discovery - Many Distinct 404 Paths

A single client requested 15 or more distinct non-existent paths in two minutes (directory brute forcing).

- **Severity:** low
- **Logic:** value_count over ['soc_web_404'] grouped by ['src_ip'] within 2m, condition {'gte': 15, 'field': 'http_path'}
- **ATT&CK:** T1595.003 Active Scanning: Wordlist Scanning; tactics: reconnaissance
- **Known false positives:** Authorized vulnerability scanners outside the allowlisted range; Broken front-end build requesting many missing assets
- **Tuning:** Maintain the scanner allowlist in the rule filter; Weight by user-agent and subsequent 200s
- **Limitations:** Slow scans (<15 distinct paths per 2 minutes) and scans spread across IPs evade the threshold.

- **Source file:** `rules/web.yml`

## SOC-WEB-002 - Web Request Containing Traversal or Injection Markers

Request path/query contains common path traversal, SQL injection or script injection markers.

- **Severity:** medium
- **Logic:** single-event Sigma selection
- **ATT&CK:** T1190 Exploit Public-Facing Application; tactics: initial-access
- **Known false positives:** Security testing from non-allowlisted hosts; Documentation or search pages that legitimately contain these strings in a query
- **Tuning:** Alert only when the response is 200/500, or aggregate per source
- **Limitations:** Signature-style; trivial encodings or novel payloads are not matched. A match does not mean the attack succeeded.
- **Runbook:** [docs/runbooks/web.md#soc-web-002](../docs/runbooks/web.md#soc-web-002)
- **Source file:** `rules/web.yml`
